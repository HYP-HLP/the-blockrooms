# The Blockrooms

*卡出现实。欢迎来到无尽的黄色房间——如果你能活着离开的话。*

**The Blockrooms** 是一款 Minecraft（NeoForge）同人恐怖生存拓展模组，把整个世界变成"块室"：一层接一层程序化生成的后室风格房间、隧道与走廊，每一层都有自己的规则、威胁与秘密。

> ⚠️ **二创声明**：本模组是基于**后室（Backrooms）IP** 与**块室（The Blockrooms）IP** 的**非官方二次创作**，与原始 IP 权利方无任何隶属、背书或赞助关系。后室与块室的知识产权归其各自权利人所有，本模组仅以独立同人项目的形式向其致敬。

## 🌐 域层一览

| 域层 | 名称 | 内容 |
|---|---|---|
| **BlockLevel 0** | 开端 | 黄色砂岩房间与潮湿地毯无限延伸，红石灯图案照明。经典卡出目的地。 |
| **BlockLevel 1** | 石英大厅 | 宜居石英大厅与 Beta 基地。传感火把与传感红石灯随昼夜切换——乘电梯深入。 |
| **BlockLevel 2** | 隧道 | 石砖与陶瓦构成的隧道迷宫。待在红石火把附近——黑暗里潜伏着怪物。机器嗡嗡作响，死亡之花悄然盛开。 |
| **BlockLevel 4** | 随机种子 | 类主世界地形，但规则残酷：多数怪物不掉落、白天怪物免伤、中毒永不结束。 |
| **The Gallery** | 画廊 | 挂满画作的无尽走廊。每条廊道中唯一一幅 4×3 矮画就是通道——穿过去，抵达下一条廊道。 |

更多域层（BlockLevel 3、5–8、Hub）开发中。

## 🎮 玩法与物品

- **真·卡出（No-clip）**：在墙里窒息——或按下**卡出键（N）**——跌落现实进入块室，落点按卡出的方块路由。
- **杏仁水桶**——后室经典解渴饮品。
- **Ruby 工具套装**——红宝石打造的剑、铲、镐、斧、锄与长矛；另有**线斧**。
- **枪弓（Gunbow）**——会自动吞掉你背包里随机物品、并将其射向敌人的弓（箭、鸡蛋、TNT、方块……应有尽有）。
- **萤石灯笼**与**动态光照**：手持萤石粉，以客户端泛洪光照点亮黑暗。
- **石英电梯**——跳跃或潜行，向该方向最多 16 格传送到下一块电梯。
- **错误合成台**——既支持原版配方，也支持"错误配方"……但取出产物时有 **5% 概率获得恶心效果**。不会解锁进配方书。
- **传感火把 / 传感红石灯**——在 BlockLevel 1 中随昼夜变化的光源。
- **传送方块**——数据驱动的结构友好型传送器（NBT 目标列表、每实体冷却），供地图作者与生成结构使用。
- **软圆石 / 加工软圆石**——危险的零食：前者吃下去会受伤，加工过的版本则提供抗性提升。
- **嗜血僵尸**——画廊的住户，任意光照下都会生成。
- **颤抖效果**、**Blockrooms 版本标题界面**等更多内容。

## 🖥️ HUD 与集成

- **域层信息面板**——进入新域层时，右下角以打字机效果逐字介绍该层（尺寸自适应、可滚动、停留后淡出）。
- **生存难度面板**——域层内右上角常驻：**safe / security / entity** 三项评级，颜色完全可定制。
- 两个面板**完全数据驱动**：`assets/blockrooms/level_info/` 下的 lang 风格 JSON 文件，可用资源包覆盖、可为任意维度新增条目——无需改代码。
- **JEI 集成**（可选）：专属"错误合成"配方分类，支持一键转移。
- 内置本地化：**简体中文 & English**，随客户端语言即时切换。

## 📦 环境要求

- Minecraft **1.21.11**
- NeoForge **21.11.x**（Java 21）
- JEI 为**可选**——不装也能正常运行。
