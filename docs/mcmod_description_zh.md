# The Blockrooms（块室）

**模组简介：** 一款将 Minecraft 世界变成"块室"的同人恐怖生存拓展模组。卡出现实，进入一层又一层程序化生成的后室风格房间、隧道与走廊——每一层都有自己的规则、威胁与秘密。

## 玩法特色

- **真·卡出（No-clip）**：在墙里窒息，或按下**卡出键（N）**，即可跌出世界进入块室；落点按卡出的方块进行维度路由。
- **层间传送**：石英电梯（跳跃/潜行向指定方向搜索最多 16 格）、传送方块（数据驱动、结构友好，NBT 目标列表 + 每实体冷却）。
- **枪弓（Gunbow）**：每 20 tick 有 15% 概率自动吞入背包随机物品，右键发射，按弹药类型分发（箭矢、鸡蛋、TNT、方块、物品弹射物等）。
- **动态光照**（客户端）：手持萤石粉时以玩家为光源做泛洪光照，点亮黑暗。
- **错误合成**：专属配方类型 + 专属界面；取产物有 5% 概率获得恶心效果；不在配方书中解锁。
- **传感光源**：传感火把 / 传感红石灯在 BlockLevel 1 中随昼夜变化自动点亮熄灭。
- **特殊维度规则**：如 BlockLevel 4 中 40% 怪物不掉落（精准采集除外）、白天怪物免伤、玩家中毒无限时长等。
- **颤抖效果**、**Blockrooms 版本标题界面**等更多内容。

## 域层介绍

| 域层 | 名称 | 内容 |
|---|---|---|
| **BlockLevel 0** | 开端 | 黄色砂岩房间与潮湿地毯无限延伸，红石灯图案照明；存在变异区域（灯灭、地毯断开、天花板破洞）与 B.M.E.G. 前哨站、橡木出口等结构。 |
| **BlockLevel 1** | 石英大厅 | 宜居石英大厅与 Beta 基地，电梯竖井连接多层，传感灯随昼夜切换。 |
| **BlockLevel 2** | 隧道 | 石砖与陶瓦构成的隧道迷宫，红石火把是唯一光源；黑暗里潜伏着怪物，隧道中散布铁块、凋零玫瑰花盆与未知机器，箱子/潜影盒藏有物资。 |
| **BlockLevel 4** | 随机种子 | 类主世界噪声地形，基岩底抬升至 y=-50；规则残酷，见上文"特殊维度规则"。 |
| **The Gallery** | 画廊 | 挂满画作的无尽走廊；每条廊道中唯一一幅 4×3 矮画就是通道，穿过去可抵达下一条廊道。 |

更多域层（BlockLevel 3、5~8、Hub）开发中。

## 内容一览

- **方块**：加热铁块、错误合成台、石制合成台、传感火把 / 传感墙上火把 / 传感红石灯、石英电梯、传送方块、软圆石、加工软圆石。
- **物品**：杏仁水桶、红宝石（Blockrooms Ruby）、Ruby 工具套装（剑/铲/镐/斧/锄/长矛）、线斧、萤石灯笼、枪弓、木棍捆、嗜血僵尸刷怪蛋。
- **实体**：物品弹射物（item_projectile，含唱片等子类）、方块弹射物（block_projectile）、嗜血僵尸（blood_zombie，任意光照可生成）。
- **音效**：主菜单音乐（C418 - Beginning）、BlockLevel 1 环境音效。
- **效果**：颤抖（Trembling，负面）。

## HUD 与模组联动

- **域层信息面板**：进入新域层时，右下角以打字机效果逐字显示该层介绍；尺寸自适应内容，超限可滚动，显示完淡出。
- **生存难度面板**：域层内右上角常驻显示 safe / security / entity 三项评级，颜色完全可定制。
- 两个面板**完全数据驱动**：内容来自 `assets/blockrooms/level_info/` 下的 lang 风格 JSON（内置简体中文与英文），可用资源包覆盖、可为任意维度新增条目，无需改代码；切换客户端语言即时刷新。
- **JEI 联动**（可选依赖）：专属"错误合成"配方分类，支持一键转移。

## 配置

- 通用：`ruby_trans_time`（绿宝石转化红宝石所需 tick，默认 1200）。
- 客户端（游戏内 Mods → 配置，或 `client.toml`）：域层信息面板开关/打字速度/行延迟/停留时间/最大宽度/最大行数、生存难度面板开关。
